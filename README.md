## 🚀 Featured Project

### [SentinelOps — Autonomous AI Dispute Resolution System](https://github.com/SEU-USUARIO/sentinelops)

Enterprise-grade Multi-Agent system engineered to automate financial disputes, chargebacks, and logistics issues in high-volume platforms.

**Engineering Highlights:**
* **Stateful Orchestration:** Multi-agent state machines with **LangGraph**.
* **FinOps Dual-Brain:** Micro-routing via local **Qwen 2.5 (Ollama)** and deep investigation via **Google Gemini 3.6 Flash**.
* **Semantic Caching:** High-speed vector caching with **FAISS** and structured validation with **DuckDB**.
* **Layered AI Defense (WAF):** Multi-stage defense combining heuristic regex, **Llama Guard 3**, and **Llama Prompt Guard 2**.
* **Privacy by Design:** Air-gapped local PII redaction using **Microsoft Presidio** before cloud transit.
* **Resilience & SRE:** Circuit Breaker with automated fallback to secondary LLMs (Groq) and automated CI/CD gating.
